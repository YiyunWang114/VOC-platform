# VoC 客户之声分析平台

面向中小新消费品牌的轻量 VoC / Consumer Intelligence 平台——把散落在各渠道的消费者口碑「统一收进来、自动理解」，转化为可行动的洞察。

> 一个品牌（或产品）的反馈天然散落在电商评论、社媒讨论、客服工单、私域社群等多个渠道。大企业有 Medallia / Qualtrics 这样的完整 VoC 体系，中小品牌却买不起、也用不动。本项目用「持续在线的轻量 AI 平台」替代「人肉刷帖 + 一次性报告」，让品牌 / 市场负责人一个人就能跑完整个口碑闭环。

---

## 核心亮点

- **四层 AI 洞察链路**：情感打标 → 主题聚类 → 观点摘要 → 洞察生成，用真实淘宝评论数据跑通并产出可展示的洞察报告（见 `p0-2/` 目录）
- **强制引证的洞察**：每条 AI 结论必须回溯到原始评论原文，杜绝「看似有理实则无据」的编造
- **品类化话题字典**：防止标签发散，话题白名单按品类定制并预留「其他」兜底
- **字段级数据治理**：识别并绕开不可信字段（评分恒为 1、好评/中评失真），以正文语义为准

## 功能模块

| 模块 | 说明 |
| --- | --- |
| 数据导入 | 上传 / 粘贴 / Webhook 多渠道接入，异步处理 + 进度追踪 |
| 数据大厅 | 反馈统一视图：筛选、搜索、标签查看 |
| AI 语义分析 | 逐条情感判定 + 话题标注 + 核心痛点提炼 |
| BI 看板 | 情感分布、话题分布、趋势等可视化 |
| 智能报告 | 诊断 / 竞品对比 / 产品深度三类报告的 AI 生成与导出 |
| 竞品洞察 | 竞品品牌配置、动态告警、对比分析 |
| 权限管理 | 基于角色的访问控制（RBAC），同心圆权限模型 |

## 技术栈

- **框架**：Next.js 14（App Router）+ React 18 + TypeScript
- **数据库**：Prisma + SQLite（本地开发）
- **AI**：DeepSeek（deepseek-chat），带重试 / 降级兜底
- **UI**：Tailwind CSS + Radix UI + Recharts + Mermaid
- **认证**：JWT（jose）+ bcrypt 密码哈希
- **报告导出**：docx

## 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 配置环境变量（复制示例并填入你的 DeepSeek API Key）
cp .env.example .env

# 3. 初始化数据库
npx prisma migrate dev

# 4. 启动开发服务器
npm run dev
```

打开 http://localhost:3000 即可访问。

## 环境变量

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `DATABASE_URL` | 是 | 数据库连接串，本地默认 `file:./dev.db` |
| `DEEPSEEK_API_KEY` | 否 | AI 分析用；缺省时自动降级到本地规则引擎（`AI_MOCK`） |
| `AI_MOCK` | 否 | `true` 强制使用本地规则引擎，便于无 Key 演示 |
| `JWT_SECRET` | 否 | 登录签名密钥；留空则运行时生成临时密钥 |
