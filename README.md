# VoC 客户之声分析平台

> 面向中小品牌、把分散消费者反馈转化为可行动洞察的 AI 客户之声（VoC）平台。
>
> AI-powered VoC platform that turns scattered consumer feedback into actionable insights for small & emerging brands.

一个品牌的口碑天然散落在电商评论、社媒讨论、客服工单里。大企业有 Medallia / Qualtrics，中小品牌却买不起也用不动。本项目用「持续在线的轻量 AI 平台」替代「人肉刷帖 + 一次性报告」，让品牌 / 市场负责人一个人就能跑完整个口碑闭环。

---

## 这个作品集展示了什么

**一个完整的 AI 产品经理工作闭环**：不是只有代码，也不是只有文档，而是「产品定位 → 需求洞察 → 方案设计 → AI 能力定义 → 真实数据验证 → 可展示洞察」的完整链路。

- 我如何把模糊的「口碑分析」收敛成可交付的产品
- 我如何定义 AI 能力的分层边界与兜底规则
- 我如何用真实数据跑通 AI 链路，并面对真实翻车点迭代

---

## 核心亮点

- **四层 AI 洞察链路**：情感打标 → 主题聚类 → 观点摘要 → 洞察生成，用真实淘宝评论（2.2 万行原始数据）跑通
- **强制引证的洞察**：每条 AI 结论必须回溯到原始评论原文，杜绝「看似有理实则无据」的编造
- **品类化话题字典**：防止标签发散，话题白名单按品类定制并预留「其他」兜底
- **字段级数据治理**：识别并绕开不可信字段（评分恒为 1、好评/中评失真），以正文语义为准

## 快速开始

```bash
cd voc-platform
npm install
cp .env.example .env   # 填入你的 DeepSeek API Key（缺省则自动用本地规则引擎演示）
npx prisma migrate dev
npm run dev
```

打开 http://localhost:3000 即可访问。
